# ============================================================
# 强制走代理 —— 优先级高于 gfwlist 的 @@ 白名单
# ============================================================
#
# 语法和 custom-direct.txt 完全一样：
#   example.com          该域名 + 所有子域
#   full:example.com     只匹配这一个主机名
#   *.cdn.example.com    等价于 cdn.example.com
#   img*.example.com     主机名通配
#   203.0.113.7          单个 IP
#   203.0.113.0/24       IP 网段
#   keyword:/download/   整条 URL 含该子串（慎用）
#   行尾可以用   # 注释
#
# 提醒：命中这里的流量，如果所有代理都连不上，会按 config 里的
#       fallback 处理。默认 "block"（返回一个连不通的地址，直接失败），
#       不会偷偷降级成直连泄露出去。
