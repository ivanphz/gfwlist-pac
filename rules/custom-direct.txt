# ============================================================
# 强制直连 —— 优先级最高，会盖掉 gfwlist 和第三方清单
# ============================================================
#
# 语法：
#   example.com          该域名 + 所有子域
#   full:example.com     只匹配这一个主机名，子域不算
#   cn                   单段 = 顶级域后缀，所有 *.cn 直连
#   *.cdn.example.com    等价于 cdn.example.com
#   img*.example.com     主机名通配（走 shExpMatch，别写太多）
#   223.5.5.5            单个 IP
#   223.5.5.0/24         IP 网段
#   keyword:/internal/   整条 URL 含该子串（慎用，每个请求都要扫）
#   行尾可以用   # 注释
#
# 注意：更长的规则总是先命中。写了 cn 之后，gfwlist 里的
#       futu.cn / bloomberg.cn 等 15 个 .cn 域名仍然走代理，
#       因为它们比 cn 更长、更具体 —— 这是对的。
